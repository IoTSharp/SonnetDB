# SonnetDB Parity Results

Parity reports are generated by `.github/workflows/parity.yml` and stored under `runs/<workflow-run-id>/`.
The repository-root `latest.md` and `latest.json` files contain the newest full-profile summary.
If the full artifact is missing, those files explicitly report `NOT_READY`; such a run is retained for diagnostics and is not release evidence.
