# GH-Issue #395：EF JSON ExecuteUpdate 固定标量路径

日期：2026-11-05（Asia/Shanghai）。实现基线：`a7125ffb15c3d2182ff811036173316c75329ba9`；本报告描述独立工作树中的源码切片，不是新公开版本的交付声明。

## 支持范围

`ExecuteUpdate` 和 `ExecuteUpdateAsync` 现在可直接更新 `OwnsOne(...).ToJson(...)` 与 `ComplexProperty(...).ToJson(...)` 容器中的固定标量属性，包含嵌套属性。首批类型为 `string`、`bool`、`byte`、`short`、`int`、`long`、有限 `float` / `double` 及其可空形式；属性映射不能包含转换器。JSON 名称保持模型原始拼写，名称中的引号、点、Unicode 只作为精确键处理。

查询限单一关系表及 EF 可直接翻译的无分组/排序/分页形状。单条更新最多处理 64 个 setter，路径最多 64 个属性片段、1024 字符。路径和输入值均由 EF 参数绑定，不把内容拼进 SQL，也不先读取实体再回写。

同一 JSON 列的多个 setter 合成为一个 `json_set_value` 嵌套表达式，按 `SetProperty` 的声明顺序执行；重复目标路径由后一个 setter 决定最终值，右侧表达式按 SQL 更新合同读取更新前的行。可以在同一语句内修改普通列。JSON 路径外的对象、数组、未知属性及数值原始文本由现有 Core 更新函数保留。已存在父级必须是对象，缺失的末端属性可创建；null 值写为 JSON null。

并发 Token 与普通 EF 批量更新一致：`ExecuteUpdate` 不读取 ChangeTracker 中的原值，调用者须将 Token 放入 `Where`，并检查返回的实际影响行数。显式事务支持提交、事务内可见性和回滚。

## 实现与兼容性

新增查询 visitor 与 factory，注册到 provider 的既有服务入口；使用 EF 的 `TranslateExecuteUpdate`、`TranslateLambdaExpression` 和运行时参数注册扩展点。普通非 JSON 更新继续使用 EF 基类路径。没有 suppress EF1001、压制 IL/trim/AOT 诊断或调用反射型 `JsonSerializer` 重载。Core、存储格式、Frame 格式和已有公开方法签名均未修改。

SQL 生成器仅放行 visitor 生成的 `json_set_value` 列表达式，保留其它整容器写法的拒绝。EF Provider 现有非 NativeAOT 边界保持不变。

## 拒绝与未完成范围

集合元素、`OwnsMany` 生命周期、对象/数组子树 `SetProperty`、Guid、日期、二进制及带转换器的属性不在本切片支持范围。数组索引和不支持标量在发出 SQL 前明确拒绝，已有 `SaveChanges` 的片段/子树更新不受此次范围限制。

`#395` 要求的对象子树/完整矩阵与公开 Provider 包的隔离消费者尚未完成，不能因本切片通过而关闭整项。源码测试使用当前工作树构建的 Provider；旧公开 5.0.0 不自动获得此功能。公开发布、正式 NuGet-only 消费者及对应最低版本仍为 `NOT_RUN`。
