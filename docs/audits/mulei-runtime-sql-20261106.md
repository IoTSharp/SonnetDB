# 木垒关系批次与有序残余查询修复

本轮基于TOLNSD现场对应源码24ff94e4，现场证据来自2026-11-06的固定专线只读核查。用户已授权源码提交、推送和现场发布；源码门禁、镜像交付和现场运行结果分别记录，不将本页的本地测试当作生产验收。

## 修改

- 关系表行与索引的原子批次只在追加WAL前有界等待checkpoint预算；批次本身超过空白预算仍拒绝，直接KV原有超限合同保留。取消、等待超时及真实I/O故障继续传播，提交开始后的故障不自动重试。
- 有序残余谓词接受显式常量CAST，类型检查仍由原求值器执行。范围值完整分组后按SQL请求列及别名绑定排序，支持现场物理BusinessId后缀与请求Id后缀不同的FIFO查询。
- 不向残余过滤前下推固定候选数量，不减少结果；保留事务overlay、混合方向、函数与列CAST等既有回退，复用原有分组溢写预算。
