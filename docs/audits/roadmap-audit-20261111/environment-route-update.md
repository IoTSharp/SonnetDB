# 环境资格路线拆分回执

日期：2026-11-11（Asia/Shanghai）。这是对路线审计之后用户新边界的文档调整回执。

## 用户边界

固定硬件、线上 Demo、现场生产、物理掉电/介质恢复和 168 小时/7 天长稳集中到独立路线；后续由用户提供 Demo/现场日志，再进行版本、机器、时间窗、负载、故障和恢复分析。当前优先补能力和缺失实现，环境资格不再作为每个代码任务的隐含阻塞。

## 已调整

- 新增[环境与现场资格路线](../../roadmap-environment-validation.md)，定义 ENV-00～ENV-06、目标登记、Demo/现场运行、固定硬件、掉电/介质、长稳、日志分析和环境发布回读。
- 根[ROADMAP](../../ROADMAP.md)将固定硬件、Demo/现场、物理掉电、介质耐久和 168 小时/7 天统一链接到环境路线；代码路线保留确定性恢复、旧格式拒绝、损坏/满盘、取消、未知提交和本地/CI门禁。
- M48 拆为 `L20A` 代码候选和 `L20B` 环境资格；M50 拆为 `T30A` 代码候选和 `T30B` 环境资格，T28/T29/T32转入环境路线。
- M42 热点并发拆为 `H07A` 代码候选和 `H07B` 环境资格；M40/M41/M19/KV专题、M25文档容量、生态 soak 入口补充环境路线归属。
- 总索引、能力成熟度、审计报告、CHANGELOG 和 HANDOFF 同步说明环境层独立判定。

## 当前状态

本轮没有连接线上 Demo、现场生产或电源控制设备，没有执行固定硬件、物理掉电、介质故障或长稳。环境路线所有任务保持 `PLANNED/NOT_RUN`。用户后续日志缺少电源、介质刷新或完整性链路时，只能判 `UNKNOWN/NOT_RUN`，不能证明物理掉电零丢失，也不能否定代码实现。

## 代码侧保留边界

单元/差分测试、确定性进程强杀、损坏/满盘、WAL/manifest 恢复、旧格式/旧二进制明确拒绝、协议/取消/未知提交、AOT/format 和本机性能计量仍由能力路线完成。环境路线只决定相应 Demo、Preview、Beta、Production 或环境 issue 的资格。

本回执没有提交、推送、部署、重启或外部写入；文档静态检查与工作树回读由后续验证收据记录。
