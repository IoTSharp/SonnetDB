# M43：本地多分区流桥接与目录任务运行

2026-10-03 增量复用已有单分区 CDC→流 outbox/receipt 桥接、持久任务目录及自动投递。不改变持久格式，也不声明远程事务。

`CdcStreamingBridgeTopology` 接收调用方打开的 1～64 个独立桥接，校验桥接标识、源/实体/分区和源数据、检查点、lease、桥接状态与目标目录的交叉冲突。轮转推进一批，单批容量沿用桥接 options，总运行受 MaxSteps、MaxElapsedTime、取消与可选批次间隔限制。同一协调器并发运行排队；宿主须独占这些桥接的推进权。

各分区独立提交和恢复，成功分区不因后续失败而回滚。`IsCaughtUp` 表示已捕获源事件已交付到目标并完成源确认；消费者 ACK 是独立位点。状态数组不构成跨分区原子快照。排队或间隔超时可以返回边界结果；批次中失败/取消继续传播，须按桥接合同重开核对 outbox。进度接收方必须快速返回，不提供强制终止回调的能力。

`FileStreamingTaskRunner(catalog, taskId, subscription, options)` 连接已登记任务和调用方已打开的真实订阅。每次运行验证目录、定义、容量及状态存在性，拒绝链接别名，然后复用 dispatcher 的有界重试和成功后 ACK。运行器从不创建、重开或关闭订阅。目录更新或删除只影响后续运行；已开始运行使用校验时的任务快照。

超时或取消不会强行停止不协作的业务函数。宿主必须等待 `HandlerCompletion` 后才关闭函数使用的订阅和其它资源；未完成时执行 lease 继续保留。默认保留耗尽批次，DLQ 必须显式选择。业务副作用幂等仍由宿主保证，不宣称 exactly-once。

真实入口 `samples/SonnetDB.CdcStreamingJourney --topology` 从两个实际 Document change feed 捕获三次变更，经独立桥接推进到注册任务订阅，故意在窗口持久提交后返回处理失败，关闭所有句柄后重开，核对稳定重投身份、去重窗口、独立源/目标位点和再次重开结果。[本轮审计](audits/roadmap-continuation-20261003.md)记录本地回归；远程拓扑、业务事务、权限与十四能力完整矩阵、固定硬件及长期门禁仍待补。
