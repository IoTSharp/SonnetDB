# SonnetDB 5.1.1：稳定性与发布验证补丁

SonnetDB 5.1.1 基于 5.0 的 API、wire 和数据库迁移合同，收口稳定版发布过程中发现的验证缺口：主 solution 现在构建独立全文进程 probe，Windows Core 的 Legacy/LSM 测试有足够的总 job 时间，Ecosystem Soak 按原子 Point WAL v2 读取 torn recovery 夹具，CrashTests 等待 ready 文件写入内容后再继续。

## 已验证发布物

- GitHub Release：[v5.1.1](https://github.com/IoTSharp/SonnetDB/releases/tag/v5.1.1)，包含 NuGet、SDK/Server bundle、安装包、连接器和校验文件。
- NuGet：十个预期包均以 `5.1.1` 公开可下载。
- Docker Hub：`iotsharp/sonnetdb:5.1.1` 已公开读回。
- GitHub Actions：CI、AOT、Format、CodeQL、Connectors、Docker、Management、Parity、Document soak、Ecosystem soak、M19 和 M39 均绑定同一提交并通过适用门禁。

## 边界

EF Provider NativeAOT、完整九模型 typed Client、固定硬件、干净系统安装、时序 us/ns、物理掉电、168 小时长稳和 IoTSharp 真实消费者仍按各自路线独立验收。单库备份仍不覆盖 Server 实例级 MQ、身份配置和外部对象。
