# SonnetDB.Core 3.1.0

本次版本是 `SonnetDB.Core` 的依赖交付，用于让独立消费者通过固定 `PackageReference` 使用当前公开的原生属性图 API。它不是完整 SonnetDB 产品发布，也不改变“八种数据模型，一套引擎”的正式产品定位。

## Public Graph API

- `SonnetDB.Graphs.GraphManager` 管理图目录和生命周期。
- `SonnetDB.Graphs.GraphStore` 提供 transaction、statement read snapshot、索引维护、checkpoint 和 compaction 入口。
- `GraphTransaction`、`GraphReadSession`、`GraphCursor<T>`、typed property/value、Expand、BFS/DFS、shortest path 和 weighted path 合同随 Core 程序集发布。
- Graph 复用 Core 的 KV/WAL/checkpoint/backup 地基，不引入第二套运行时依赖。

这些 public API 是相对 `3.0.1` 的兼容性扩展，因此版本按 SemVer 升到 `3.1.0`。`3.0.1` 不包含 `SonnetDB.Graphs.GraphStore`，不能作为图能力依赖。

`3.1.0` 同时保留 `3.0.1` 已发布的 `TokenKind` 数值，以及 `TableSchema.Create`、`CreateTableStatement`、`SelectStatement` 和 `SqlExplainExecutionResult` 的旧位置参数/解构签名。发布包必须通过以 NuGet `SonnetDB.Core 3.0.1` 为 baseline 的 package validation，不使用 ApiCompat suppression。

## Couplet CPL-007

Couplet 可在包发布后把临时 commit-pinned `ProjectReference` 切换为：

```xml
<PackageReference Include="SonnetDB.Core" Version="3.1.0" />
```

正式切换仍应更新 central package version、lock files、许可证/依赖清单，并重新运行 Couplet 的 public type、trim 和 Native AOT 验证。此版本只解除 CPL-007 的包可用性阻塞，不实现 CPL-003、CPL-004 或 C1。

## Package Metadata

- Target framework: `net10.0`
- License: MIT (`PackageLicenseExpression`)
- Runtime dependencies: `System.IO.Hashing 10.0.10`、`System.Numerics.Tensors 10.0.10`
- JSON: 生产序列化继续使用 source-generated `JsonSerializerContext` / `JsonTypeInfo<T>`；Graph 持久结构使用显式 codec，JSON property value 只做结构校验。
- Trim / AOT: Core 继续启用 `IsAotCompatible`、trim analyzer 和 AOT analyzer，发布验证要求 0 个未处置 IL/AOT warning。

## Scope Boundary

M40 的固定硬件、Neo4j/PostgreSQL 语义对拍、LDBC/Graphalytics、完整 Native AOT journey、Couplet C2~C4 联合门禁和 7 天生产证据仍按路线图保持未完成。发布 `SonnetDB.Core 3.1.0` 不代表 Native Graph Preview、Graph Beta 或 Production 门禁通过，也不构成九模型产品定位声明。

## Verification

发布前至少执行：

```powershell
dotnet restore SonnetDB.slnx --locked-mode
dotnet build SonnetDB.slnx --configuration Release --no-restore /warnaserror
dotnet test tests/SonnetDB.Core.Tests/SonnetDB.Core.Tests.csproj --configuration Release --no-build
.\eng\release.ps1 -Tasks nuget -Version 3.1.0
dotnet pack src/SonnetDB.Core/SonnetDB.Core.csproj --configuration Release --no-restore `
  -p:PackageVersion=3.1.0 -p:EnablePackageValidation=true `
  -p:PackageValidationBaselineVersion=3.0.1
```

还需从生成的 `SonnetDB.Core.3.1.0.nupkg` 独立还原 consumer，确认导出的 `SonnetDB.Graphs.GraphStore`、依赖闭包、MIT 元数据、程序集 trim/AOT 标记、source commit 和 SHA-256。
