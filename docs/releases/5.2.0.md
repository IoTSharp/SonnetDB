# SonnetDB 5.2.0

- 新增 `SonnetDB.Quartz` 包。Quartz.NET 3.18.2 单实例应用可以通过 SonnetDB 保存作业、触发器和调度状态。应用重启后可恢复原有作业、暂停状态和下一次触发时间。
- Server 增加数据备份调度和校验后恢复到新数据库的能力。在线恢复默认关闭。
- 对象桶正文可通过 `SonnetDBServer:ObjectStorage:RootDirectory` 配置到独立存储卷。
- 关系 SQL 增加 `ON CONFLICT DO SELECT`，并优化特定主键条件下的 `COUNT(*)` 和分组计数。

Quartz 首次启用时先准备调度表。保持调度器、作业和触发器标识，应用重启后可沿用原有记录。组件的使用方式和范围见包内 README。
