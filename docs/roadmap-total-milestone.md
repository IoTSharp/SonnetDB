# SonnetDB 总里程碑：十四套能力

**核查日期：2026-09-21；本文件只保留未闭环实现、后置验证和 M43 后续队列。**

此前总里程碑中的已完成实现、测试和本地门禁已移入 [`CHANGELOG.md` 的路线图归档](../CHANGELOG.md#roadmap-completed-archive-2026-09-21)。本文件是当前执行索引，不重复记录已关闭 PR 的逐项设计；历史背景和旧 PR 拆分见 [`docs/roadmap-history.md`](roadmap-history.md)。

**状态图例：** ✅ 本条所述代码/文档范围完成；🟡 本机或配置级完成、外部真机/发布证据待补；🚧 部分实现或仍有代码残余；❌ 已执行但未通过；📋 尚未实施；⏳ 后置验证或外部结果待执行；➡️ 已移交。

**完成判定：** 代码、真实产品入口、主要合同回归、文档边界和对应证据必须同时成立。测试或本机 smoke 不能替代固定硬件、远程 parity、安装、外部对拍、长稳或生产门禁。

## 一、当前结论

SonnetDB 当前公开定位为九种原生数据模型，加上空间/轨迹、流处理/订阅、CDC/边缘同步、AI/RAG、治理/运维五项平台能力，共十四套能力。Graph 保持 Graph Beta；“有代码入口”不等于完成容量、恢复、跨端 parity 或生产发布证据。

当前最重要的未闭环项：

- **M20：** 最新七次 scheduled 窗口全部失败；MinIO 启动阻断已在本地修复，修复后的连续七次远程窗口仍未取得。
- **M19/M25/M29/M40：** 主要剩固定硬件容量、干净安装、外部数据库对拍、Native AOT、跨进程恢复和长稳报告。
- **M27/M35：** 真实目标模型质量、成本、双网部署、RAG 质量评测、回滚和固定硬件证据仍未闭环；tiny fixture/hash fallback 不计真实语义证据。
- **M36：** #311~#326 代码合同已完成；九模型 golden journey、远程恢复、对象/MQ 现场和长期证据独立后置。
- **M41/M42：** 本地规划器、资源边界和部分热路径已完成；标准关系 JOIN、KV state 独立读预算等代码切片已有本地回归。统一语料下的固定 x64/ARM64、168 小时 mixed workload、I/O/冷启动和发布门禁仍待执行。
- **M43：** #382~#384 的索引与成熟度口径已完成；#385~#395 已有首批本地合同（CDC 编解码与 append/replay/ack spool、订阅与文件 checkpoint），#396 的索引门禁已完成；CDC/流处理的远程拓扑、组合旅程、发布汇总和生态资料仍未闭环。

## 五、最终完成判定

M43 只有在以下条件同时满足时才能标记完成：

1. 十四项能力的名称、分类、成熟度和公开边界在中英文材料中一致。
2. 十四项能力各有真实入口、权限/失败/取消/重启/结果对账的 golden journey；mock、fixture、浏览器 UI 与真实服务证据分开记录。
3. 九个原生模型的生产状态可追踪，Graph 的 Beta 边界保持明确；M20 nightly、M19/M25/M29/M40/M41/M42 的适用发布门禁有绑定硬件和原始报告。
4. CDC/同步与流处理分别拥有版本化合同、检查点、恢复测试和明确拓扑；外部 issue 队列按依赖顺序单独闭环。
5. AI/RAG 的真实模型质量、延迟、成本、数据出域、删除同步和回滚边界已公开，不能把 hash fallback 或 tiny fixture 写成真实模型 PASS。
6. 证据报告、代码、文档和 release commit 绑定，Core 继续满足 Safe-only、零第三方运行时依赖、source-generated JSON、Native AOT 和 public API 中文 XML 文档约束。

在上述条件前，长期产品表述只能准确说明已验证范围，并明确列出 `NOT_READY`、`DEFERRED`、Graph Beta 和不承诺的兼容边界。
