# M47 工作台交互、反馈与状态合同

**状态：设计草案 / 原型评审基线，2026-10-04。** 本文服务于 [M47 统一数据库管理工作台](../m47-unified-management-workbench.md)，复用 [M29 交互规范](../m29-workbench-redesign/interaction-spec.md) 和已有 `web/src` 能力。本文中的状态、流程和文案是后续设计与实现的合同，不表示所有生产入口已经满足。

## 1. 设计顺序与确认门禁

本轮按以下顺序展开，并在同一个可点击 HTML 原型中保留前一阶段已经确认的上下文：

1. **外轮廓**：先确认顶部、左侧功能轨与 Explorer、中间工作区、右侧 Inspector、底部结果与状态，以及对话框、抽屉和提示的层级关系。
2. **一级导航**：确认全局模块、菜单名称、入口位置、当前连接/数据库上下文和三个宿主的范围。
3. **二级导航**：确认九模型各自的任务页签、对象打开/复用、深链接、结果和详情的切换。
4. **页面细节**：确认各页查询器、表格、表单、检查器和适用状态，以及关键操作的完整流程。
5. **原型确认后生产实现**：获得用户对以上原型的确认后，再把最终设计按像素和交互合同接入生产代码。原型制作、文档盘点与可点击状态验证可先进行；不得把“原型已生成”当作“设计已确认”。

原型使用**示例数据和状态模拟，不向 Server 发送网络请求**。连接健康、权限、审批、取消、任务恢复、Studio bridge、VS Code 转交和错误均用于设计评审，不代表真实安装、认证、权限、恢复或发布证据。原型中的成功提示不能改变 M47 或独立发布门禁的 `NOT_READY` 判定。

本轮尺寸基线：Inspector 默认 **344px**，可调范围 **320–520px**；M29 的 384px 保留为参考值。历史抽屉默认 **440px**，M29 的 420px 保留为参考值。普通对话框默认 **620px**，写审批扩为 **720px**。所有覆盖层均受视口宽高约束，正文独立滚动、标题和操作区保持可见；不得为保住固定宽度而挤压中央工作区。

## 2. 组件交互目录

| 组件 | 入口与职责 | 默认行为 | 必须保留的上下文 |
|---|---|---|---|
| 顶部 Connection Selector | 连接/数据库选择，连接健康详情 | 当前连接与库持续可见；配置编辑另开对话框 | connectionId、端点、数据库、宿主、最后检查时间 |
| Command Center | Ctrl+K，命令/对象/最近工作区搜索 | 导航或建立草稿；危险动作进入审批 | 当前连接/库、目标对象、能力原因 |
| 一级功能轨 | 切换全局任务模块 | 唯一明确的激活项；图标与文字共同表达 | 当前连接、库、保留的工作区 |
| Explorer | 数据库与九模型资源树 | 单击预览；双击或 Enter 固定页签；分组独立重试 | 对象原名、模型、树展开与滚动位置 |
| Workspace Tabs | SQL、对象、Notebook 等任务上下文 | 同一对象复用页签；修饰键可另开；有草稿时关闭前提示 | 连接/库/对象、二级页签、查询、过滤器 |
| 二级 Section Tabs | 当前模型内部任务 | 使用任务名称；可深链接；支持前进/后退 | 当前对象与查询过滤上下文 |
| Capability Bar | 查询/编辑/导入/治理/监控能力 | 禁用项显示原因；能力源自真实权限与端点 | 权限快照、宿主、能力更新时间 |
| Result Plane | 中央底部 Table/Raw/JSON/Chart/Map/Explain | 不因后台新结果抢焦点；可收起和调整高度 | 语句、连接/库、结果时间、耗时、预算 |
| Inspector | 选中行、文档、key、消息、对象或图元素详情 | 无选中项时提示选择；复杂编辑进入任务页签 | 身份、metadata、payload、适用动作 |
| Form Dialog | 新建连接/数据库、重命名等有限输入 | 字段级验证；明确提交动作；失败保留输入 | 目标连接/库、字段与错误 |
| Write Approval | 暂存预览、风险、预检与人工确认 | 普通写主操作色；危险动作危险色；执行中防误关闭 | 连接/库/对象、影响范围、请求摘要、审批版本 |
| Import Stepper | 文件、映射、预检、执行、报告 | 每步完成条件清楚；可返回修改并使预览失效 | 文件身份、格式、映射、目标、进度 |
| Task Drawer | 导入、上传、导出、重建等长任务 | 显示明确终态和可用操作；关闭抽屉不等于取消任务 | taskId、开始时间、范围、进度、恢复能力 |
| History Drawer | 本机工作台历史，右侧覆盖打开 | 连接/库/模型/状态/时间筛选；恢复输入不执行 | 查询或操作、目标、耗时、结果摘要 |
| Audit View | 服务端可验证审计 | 与本机历史明确区分；提供操作关联 | 操作者、服务端时间、operationId、执行结果 |
| Inline Status / Banner | 只读、离线、无权限、局部失败、截断 | 持续问题持续可见，并提供下一步 | 发生范围、时间、原因、可用操作 |
| Toast / Popconfirm | 即时反馈与低风险轻量确认 | 不代替持续错误与危险审批 | 动作对象及结果摘要 |

Explorer、Inspector 与 Result Plane 仍是同一个工作区的不同区域，不重复建立独立全局导航。连接切换、数据库切换或页面跳转不允许自动重放先前写入。

## 3. 反馈层级与选型

| 形式 | 适用情况 | 文案与关闭规则 |
|---|---|---|
| 字段旁错误 | 名称非法、必填项缺失、格式错误 | 指向具体字段和修正方法；输入修正后重新验证 |
| 页内 alert | 当前任务失败、预检失败、部分结果错误 | 保留草稿/结果；提供局部重试或查看详情，不刷新整个应用 |
| 持续 banner | Offline、只读、权限变化、截断、执行结果待核对 | 原因消除或用户明确处置后更新；关闭不恢复被限制的能力 |
| 状态条 | 当前连接、执行中、完成摘要、结果时间 | 简短、可展开详情；不能只用颜色表达 |
| Toast | 复制完成、配置保存完成、文件保存完成 | 无需用户后续处理；失败若需修正必须同时在原任务中留痕 |
| Popconfirm | 清除本机历史、移除连接配置 | 明确动作与对象；默认焦点在取消；不用于删除数据库/数据 |
| Form Dialog | 有限字段的创建/修改 | 字段 label、验证与主操作明确；提交中禁止意外关闭 |
| Approval Dialog | 数据写入、删除、导入、重建、治理变更 | 实际动作、影响范围与风险可读；确认不是泛化“确定” |
| Drawer | 历史、任务、详情浏览等延续性任务 | 可以关闭后回到工作区；关闭不是停止、回滚或删除 |

不为同一失败同时堆叠 toast、modal 和 banner。原型可用“查看错误详情”展开错误码、请求标识和完整说明；生产不得显示凭据或敏感请求头。

## 4. 连接、健康与认证

连接流程：

```text
输入配置 → 字段校验 → 测试中 → 健康/不可达/超时
                              → 认证有效/会话过期
                              → 目标数据库可访问/无权限/不存在
          → 保存配置 → 显式连接 → 打开目标上下文
```

健康、认证和数据权限是三个不同结果。`/healthz` 返回健康只说明该端点的健康探测成功，不能推出已经登录、拥有 SQL 权限或目标数据库可访问。连接列表应显示健康与最近检查时间；当前工作区另显示会话和 capability 状态。

- 新建远程连接包括名称、端点、默认数据库和认证方式的明确说明。凭据由宿主安全边界处理，不进入示例 SQL、历史导出或项目配置。
- “测试连接”显示请求中、超时及失败原因；可保存未连通配置，但保存成功提示不写成连接成功。
- 当前实现的健康状态为 unknown/checking/healthy/unhealthy，并有 5 秒超时；这是复用基础，不等于认证测试已完成。
- 离线保留页签、查询草稿、最后结果和结果时间；所有服务器写入禁用，提供“检查连接”。
- 重连成功先刷新明确失效的资源分组和权限；不得自动执行历史写入或过期审批。
- 连接、库、端点、凭据或权限发生变化，待执行预览失效；跨连接页签必须展示其自己的连接身份，避免把旧页签错误标成当前连接。

## 5. 创建与删除

### 5.1 创建

```text
填写名称/参数 → 字段校验 → 目标与请求预览 → 人工确认 → 提交
                                                     → 成功：定位新对象
                                                     → 失败：保留输入与说明
```

创建页展示目标连接、数据库、对象类型和名称原始拼写。非法输入在字段旁说明，重名由服务端最终判定，不能仅依赖本机缓存。原型可预设成功、重名、无权限、离线四种结果，并标记为模拟。

已有新建数据库对话框和提交逻辑可复用；其直接 CREATE 行为不是“已统一 WriteApproval”的证据。生产迁移时应采用同一草稿/预览合同，保留轻量创建的可用性。

### 5.2 删除

删除数据库、DROP、前缀删除、批量数据删除、Multipart abort 和不可逆治理变更进入危险审批。轻量 Popconfirm 只用于清除本机记录或移除连接配置。

- 标题和主按钮写实际动作，例如“删除数据库 telemetry”或“确认删除 24 个 key”。
- 展示目标连接/库/对象、筛选条件、实际或估计影响数量、不可逆说明和适用的备份/恢复边界。
- 尚未估计影响量时写“影响数量尚未估计”，不能用命令条数代替数据条数。
- 对数据库/DROP/前缀删除等高风险操作，可要求输入目标对象原名；确认不能由 Enter 在未完整审阅时意外触发。
- 执行中停止后续动作不等于撤销已完成删除；执行结果待核对时不能重新确认同一计划。

当前数据库删除使用维护抽屉中的 Popconfirm 后直接执行 DROP，这是需要统一的具体入口，不能在设计文档里写成已有完整审批覆盖。

## 6. 写审批状态流程与预览失效

```text
Draft → Staged → Preview → Dry-run（可选）→ Awaiting confirmation
                                              → Executing
                                                  → Succeeded
                                                  → Failed
                                                  → Partially completed
                                                  → Cancelled after current batch
                                                  → Outcome unknown
```

审批展示身份（连接/库/对象）、实际动作、参数化 SQL 或请求摘要、影响范围、风险、生成时间和适用预检结果。普通写使用主操作色，危险动作使用危险色。执行失败保留草稿与可解释的预览；是否能复用原预览由重新核对结果决定。

预览在以下任一变化后进入 `Stale`：连接 ID、端点、数据库、凭据/会话、权限、宿主、对象版本、查询草稿、筛选条件、导入文件/映射或影响范围变化。无法验证对象版本时明确显示需要重新预览，不能只用固定时间窗口保证安全。现有 SQL 实现已检查页签、库、连接 ID、base URL、token 与 SQL 内容，应保留并扩为统一合同。

| 状态 | 界面与允许操作 |
|---|---|
| Draft / Staged | 可编辑、返回；尚无执行承诺 |
| Preview | 展示范围与请求；提供适用的预检入口 |
| Dry-run running | 明确预检类型；确认按钮禁用 |
| Awaiting confirmation | 普通确认或危险确认；展示最后核对上下文 |
| Stale | 持续提示“预览已失效”；只能返回编辑/重新生成 |
| Executing | 显示当前动作/进度；关闭和 Esc 不取消任务；仅在支持时显示停止入口 |
| Succeeded | 成功数量、耗时、受影响对象、结果与审计 |
| Failed / Partial | 保留草稿；显示已完成、失败和未执行部分；避免整体“失败”掩盖已写入 |
| Cancelled | 说明停止边界与已提交数量；不宣称回滚 |
| Outcome unknown | 禁止盲目重试；先查 operationId/审计/对象状态并重新核对 |

`dry-run` 必须说明是本地格式/映射校验、服务端查询预览还是服务端事务预检。没有提供服务端预检的入口显示“不支持服务端预检”，不得把本地校验或 fixture 当作真实服务端 dry-run。

## 7. 导入、停止与恢复边界

导入向导采用五步：**文件 → 映射 → 预检 → 执行 → 报告**。返回修改文件、映射、目标或覆盖策略会使后续预检与审批失效。报告始终展示文件身份、目标、格式、有效/无效行、已提交、失败、未执行数量和耗时。

当前关系导入使用每 100 条一批的事务执行。其“取消”请求在下一批开始前检查，所以用户文案应为“停止后续批次”：

```text
执行批次 → 请求停止 → 等待当前批次结果 → 不启动下一批 → 生成部分完成报告
```

已经提交的批次保留，未提交与失败批次分别报告。HTTP 中断或超时可能令当前批次结果未知，应核对服务端状态后再决定后续步骤，不将本机进度直接视作服务端全部提交事实。关闭任务抽屉、离开页签或关闭弹窗不能被隐式解释为回滚。

| 操作类型 | 可承诺的恢复 | 禁止的推断 |
|---|---|---|
| 关系导入 | 从已知报告重新建立输入与范围，重新预检/审批；没有持久 checkpoint 时明确标识 | 不宣称跨会话无重复 resume；不能直接从本机 done 数跳过数据而保证正确 |
| 对象 Multipart | 从服务端会话与分片列表选择真实会话，核对 uploadId、key、过期时间、分片状态后继续 | 会话过期/完成/中止时不能继续上传；“停止上传”和“中止并丢弃会话”不能合并为同一按钮 |
| 文档 Change Feed | 仅在服务端 resume token 有效且范围一致时续传，显示 token 过期边界 | 不把读取续传当作导入写入恢复 |
| 重建/导出等后台任务 | 依据真实 taskId 与服务端能力提供查看、停止或恢复 | 没有任务 API 时不展示可兑现的持久恢复承诺 |

对象 Multipart 服务端会话分页和恢复已有实现，是可复用的真实能力；关系导入本地映射与进度没有同等持久恢复保证。原型可以模拟两种状态，但必须分别解释其设计边界。

## 8. 错误、离线、权限与未知结果

- **局部失败**：Explorer 某模型失败只影响该分组；其他模型保持可用。错误提供原因、最近尝试时间与局部重试入口。
- **401/会话过期**：保留输入，重新登录或更新凭据；重新认证使原写审批失效。
- **403/无权限**：说明所需能力与目标，提供权限详情；仅在实际有可用申请渠道时显示申请动作。无读权限时不以缓存载荷继续展示敏感数据。
- **只读**：持续显示只读状态；编辑、删除、导入、治理入口禁用且有原因。只读与“当前宿主不提供此能力”使用不同说明。
- **离线**：保留允许保留的旧结果并标明快照时间，禁止写入；重连后不自动运行危险任务。
- **查询超时/取消**：显示已收到行是否完整、服务端取消是否得到确认；保留查询，可修改预算或缩小范围后重新运行。
- **写请求超时/网络中断**：显示“执行结果待核对”。客户端没有收到成功响应不代表服务端没有执行；禁止直接提供“再次执行”作为主动作。
- **未知写结果**：若服务端支持操作标识或幂等合同，先查操作与审计；否则检查受影响对象并显式重新预览。没有幂等保证时不能通过 UI 自动重试写入。
- **部分完成**：区分成功、失败、未执行与结果未知的范围；详情中提供可导出的报告，不把它压成一个通用错误 toast。

生产网络重试、任务轮询与健康检查都必须有次数/项目和墙钟预算、取消与合理 backoff；原型状态切换不应生成自动无限轮询。工具链执行仍遵守仓库与机器级有界执行、进程归属与清理要求。

## 9. 结果预算、cursor 降级与复制导出

Result Plane 采用同一结果语义：`columns`、`rows`、`cursor`、`hasMore`、`truncated`、`metrics` 和 `error`。具体适配器必须声明支持哪些字段与能力，不能因统一界面就推断所有 endpoint 已经有 cursor。

| 服务端能力 | 展示与交互 |
|---|---|
| 有 cursor/continuation | 展示“已加载 N 行”；按服务端游标加载下一页；上下文/查询变更使 cursor 失效 |
| 有明确页码合同 | 使用其实际页码与总数；总数未知时不编造最后一页 |
| 只有一次性有界结果 | 展示预算和已返回数量；禁用“下一页”并说明；提供缩小范围/修改查询 |
| 结果截断 | 持续显示“结果已截断”与原因（行数/字节/时间/模型预算）；返回行可查看，但不能被描述为完整集合 |
| 结果部分错误 | 保留已收到内容与错误范围；明确 completeness，避免全绿成功 |
| 服务端取消确认未知 | 显示客户端接收停止与服务端状态边界，不把关闭连接等同完整取消 |

复制与导出菜单区分“选中行”“当前已加载行”“当前筛选的已加载行”。搜索当前结果只过滤已加载内容时，输入旁说明范围，不能暗示服务器全量检索。“全部查询结果”只有在真实 continuation/流式导出能力存在时可用；否则显示不支持原因。

CSV/JSON 下载成功只说明保存完成，不表示查询覆盖全部数据。截断结果复制/导出仍须携带可见范围说明或报告信息；不得把当前 rows 数作为全库总数。对象 Range 预览、文档 payload 截断和 Graph 有界画布同样展示各自预算，不能统一误称完整对象或完整图。

新结果到达只更新未读/完成状态，不抢焦点、不自动展开覆盖编辑器。错误和无行结果也保留语句、连接/库、耗时与终态。数据为空与尚未执行、筛选无匹配、无读权限分别呈现。

## 10. 页面状态矩阵

每个任务页对以下状态做适用性判定。标为不适用时写原因与替代行为，不能用一个全局成功截图覆盖所有状态。

| 状态 | 页面要求 | 原型检查点 |
|---|---|---|
| Ready / 有数据 | 身份、主任务、结果与详情一致 | 对象切换、二级页签、选中行驱动 Inspector |
| First-use empty | 解释尚无对象/尚未执行，提供权限允许的起始动作 | 创建/连接/开始查询入口 |
| No matches | 明确筛选导致无匹配 | 清除筛选；保留查询输入 |
| Loading | 几何稳定，标明当前加载范围 | 单组 skeleton；仍可取消或切换上下文 |
| Partial failure | 成功区域仍可用，失败可局部重试 | 不整页清空；结果范围明确 |
| Error | 可理解原因，保留输入与允许保留的旧结果 | 详情、局部重试、草稿保留 |
| Read-only | 持续状态，写能力禁用且可解释 | 能力原因可键盘访问 |
| Offline | 持续提示、快照时间、重连入口 | 不自动写、不伪装实时数据 |
| Permission denied | 区分会话失效与权限不足 | 不泄露不可读取载荷 |
| Timeout / Cancelled | 说明停止和已完成边界 | 读操作可缩小范围；写操作先核对 |
| Truncated / Bounded | 预算、数量、完整性与追加能力明确 | 导出范围、cursor 降级、部分画布 |
| Stale / Dirty | 预览失效或未保存草稿明确 | 离开/关闭提示；重新生成预览 |
| Long content | 名称、JSON、宽表格、大树仍可读 | 独立滚动、复制完整值、不撑破外壳 |
| Narrow desktop | Explorer 可收起；Inspector 改为覆盖层 | 1440/1280/1100px，中央工作区保留可读宽度 |
| Host capability unavailable | 显示宿主能力边界与可用替代 | Studio bridge 降级、VS Code 转交 |

九模型覆盖入口与专用边界：

| 模型/任务面 | 除通用状态外必须覆盖 |
|---|---|
| SQL / Notebook / Explain | 多语句部分失败、结果截断、取消、草稿变更使审批失效、空结果与无结果列 |
| Measurement | 空时间窗、TAG/FIELD 长名称、稀疏数据、Chart/Trajectory 无适用列、时间与点数预算 |
| 关系 | 行编辑草稿、约束错误、真实分页能力、导入部分提交/停止报告、DDL 审批 |
| 文档 | 非法 filter/JSON、Tree/Raw、cursor 失效、payload 截断、validator 预检、feed token 过期 |
| KV | 空前缀、类型化值、二进制/Hex/Base64、TTL 到期、CAS 冲突、前缀删除影响未估计 |
| MQ | 空 topic、seek 无匹配、消息 payload 截断、消费者 lag、publish/ack 审批、实例恢复边界 |
| 向量 | 维度不匹配、profile 未配置、Top-K/filter、真实 embedding 与示例值区别、命中 Inspector |
| 全文 | 无命中、Analyzer token、highlight、重建进行中/失败、分页能力与查询预算 |
| 对象 | 空 prefix、Range/二进制预览、上传校验、Multipart 活动/过期/完成/中止/可恢复、治理审批 |
| Graph Beta | 空图/无路径、画布节点边预算、选中节点/边、staged edit、维护权限与 SQL/PGQ 拒绝边界 |
| 全局连接/历史/任务/AI Connect | 健康与 auth 分离、空历史、只恢复输入、未知写结果、宿主能力缺失、默认只读与数据出域说明 |

Graph 始终标记 Beta。分页、取消、恢复、认证和权限状态只有在真实 endpoint/宿主验收后才能成为实现证据；HTML 模拟覆盖仅证明设计路径可以评审。

## 11. 可访问性与键盘合同

- 所有图标按钮具有可访问名称；tooltip 是补充说明，不是唯一名称。颜色同时配合文本/图标，不作为权限、错误或风险的唯一表达。
- 表单字段有稳定 label；错误通过 `aria-describedby` 与字段关联。placeholder 不替代 label。
- 对话框/抽屉正确命名，模态具有 `aria-modal`、焦点陷阱、初始焦点和关闭后的触发点焦点恢复。高风险确认初始焦点放在说明或返回编辑，避免 Enter 意外执行。
- Esc 在非繁忙模态返回编辑；繁忙状态明确提供安全的停止/查看任务入口。鼠标遮罩关闭遵循同样规则，不能绕过 dirty/stale/busy 保护。
- Tabs 使用 tablist/tab/tabpanel 语义和方向键；资源 tree 支持展开/收起、方向键、Enter 固定页签与可访问的上下文动作。焦点位置与已选中对象分别表达。
- Splitter 可键盘调整、具有当前尺寸与范围；恢复展开后保留原尺寸和焦点。Inspector 覆盖打开时不能让表格焦点落到遮挡区域。
- 普通异步状态用 polite live region，阻断错误用 alert；进度包含可读的完成/总数。不以高频逐行播报淹没辅助技术。
- 新结果、新通知和后台任务完成不抢输入焦点。历史恢复先恢复可见上下文，再将焦点交给输入区，且不自动执行。
- 尊重 `prefers-reduced-motion`；减少位移和自动滚动。放大文本与窄视口时允许区域滚动，标题、危险范围和主操作不能被裁掉。
- 原型应检查键盘全旅程与焦点回归；生产仍须复核组件库和自制 Teleport 模态的实际行为。已有 ARIA 标记不能独立证明焦点管理已通过。

## 12. 三宿主转交与边界

| 宿主 | 相同语义 | 特殊交互与转交 |
|---|---|---|
| Web Admin | 同一资源上下文、结果、审批、历史与状态 | 浏览器文件能力；完整治理任务；浏览器限制通过页内说明 |
| Studio | 复用 Web 工作台页面与几何 | Managed Local、data root、Server 版本/Health/Start/Stop；native bridge 可用时使用原生文件对话框，缺失时保留 Web fallback |
| VS Code | 同一对象名称、查询输入、结果预算、只读与错误语义 | Remote-first；凭据在 SecretStorage；复杂编辑、导入、备份、治理通过深链接转交 Web Admin/Studio |

转交携带连接标识、数据库、对象、任务和必要的非敏感输入；不把 token/密钥放进 URL。目标宿主重新验证登录、权限和能力，并重新建立写审批。无法匹配连接时先要求选择或建立 profile，不能静默落到同名数据库。

Studio bridge 不可用时可以继续 Web 功能；只有用户调用原生功能时解释降级。VS Code 不通过共享页面扩大为完整治理工作台；只读 MCP 工具保持既有边界，AI 生成写入只建立草稿并转交审批，不获得额外执行权限。

原型里的宿主切换和深链接只用于比较任务与布局；它们不启动本地 Server、不安装 Studio/VSIX、不写外部客户端配置，也不验证 Extension Host、WebView2、真实凭据或权限。
