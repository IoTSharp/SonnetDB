# M49：连接器/嵌入式拆分、九模型访问与有界批处理

日期：2026-10-16（Asia/Shanghai）。状态：**实施已开始。C01/C02/D01/R02/R03 首片进行中，其余 planned；15 包均未整体完成。** 当前结果见[实施矩阵](m49-implementation-matrix.md)。

本轮按用户直接答复修订此前批量分析路线：`connectors/` 是每语言原生 HTTP/2 二进制 Frame 远程 SDK，平行 `embedded/` 是托管 .NET 与统一 Native AOT C ABI 绑定。**首批只完成九模型数据访问，允许分批正式发行，剩余语言/平台/能力后续完成。** 不保留旧 SDK/API/ABI 兼容层，直接重构。此前有界批处理、类型、资源与终态工作继续复用。

基线仍为已获取源码 `67a5c8c8d64c36002aee5ebcfcb40634e7d5f482`。现有源码尚未按新架构重构，不能将本文当作已交付能力。用户决定、源码证据、平台与非目标详见[确认需求](connector-embedded-split-requirements-20261016.md)。[根路线 M49](../../ROADMAP.md#milestone-49)保存执行索引。

## 1. 产品与语言矩阵

| 语言 | connectors 远程 | embedded 本地 | 边界 |
|---|---|---|---|
| .NET | 本语言 HTTP/2 + Frame | 直接托管引擎 | 远程包脱离 Core 运行依赖；不要求 .NET P/Invoke |
| C | C 网络库 + Frame codec | 统一 AOT C ABI、头文件与 demo | 远程不是 AOT 引擎包装 |
| Go | 本语言网络/codec、database/sql | cgo 包装统一 AOT 库 | 远程不经 cgo/引擎；context 取消与 Close |
| Rust | 本语言网络/codec | FFI 与安全封装 | 两路径分别验证所有权/RAII，不擅增 Send/Sync |
| Python | 本语言网络/codec、DB-API | ctypes 包装统一 AOT 库 | 各自有界迭代与错误/资源合同 |
| Java | Java 8 兼容网络/codec | Java 8 JNI 包装统一 AOT 库 | 优先单个兼容库；需要时隔离 Java8 包，FFM 可选 |
| VB6 | 仅远程，本语言帧处理及系统网络 API | 不支持 | 固有 x86 客户端访问 64位 Server，无 AOT/x86 引擎桥接 |
| PureBasic | 仅远程，本语言帧处理及适当网络 API | 不支持 | 不沿用 C ABI 嵌入式 include 作为新远程实现 |
| ODBC | 后续独立 driver，当前预留 | 本轮不纳入 | 不把预留目录算已实现 SDK |

目标包含 Linux、Windows、macOS，先 64 位；x64/ARM64、Linux glibc/musl 逐适用项建立矩阵，真实工具链与运行证据由 C01 冻结。语言平台限制逐项说明，不凭计划标 supported；普通 32 位引擎/库后续。VB6 固有 x86 仅为远程客户端例外。

## 2. 首批能力与协议补齐

首批为时序、关系、KV、文档、全文、向量、对象、MQ、图九模型数据访问，包括访问所需的资源/schema/索引、写入查询、模型专用操作、参数/类型、分页与生命周期。Graph 继续保留现有 beta 门槛。具体操作映射见需求矩阵，按实际引擎支持语义，不承诺完整 SQL/GQL/S3 等外部兼容。

现有 Frame service 只覆盖部分操作，SQL 写入、复杂文档/KV/对象/图等不能继续暗中走 REST。F01 必须补齐这些首批缺口，并处理适用事务、订阅、错误和必要认证。JSON 文档作为模型负载允许，不等于 REST/JSON RPC。h2c 与 TLS/ALPN 分别验证，实际协议必须为 HTTP/2。

只有具体语言确实不能满足才讨论用户允许的例外；当前没有预先豁免。Java8/BASIC 可以使用适当网络库，年龄或缺工具不是语言不能处理二进制的证据。VB6 可核验 WinHTTP API，启用 HTTP/2 后还须查询实际协议并拒绝回落；双工、取消、MQ 订阅另实跑。

AI/RAG、通用流处理、CDC、备份治理和用户/角色管理等公共 API 后续规划，不纳入首批新增范围。MQ 自身的订阅/ack/offset 仍属于模型访问；Server 现有鉴权授权、数据预算、持久性与恢复正确性照常验收。用户允许后续 AI 由显式配置外部模型/API 联网。

## 3. 为什么保留有界批处理主线

固定基线中 `NativeResult.From` 先把完整 reader 收集到 List，embedded 结果包装完整 Rows，部分 Frame 请求完整缓冲响应。首片已移除 ABI 层的完整结果副本，尚未解除 Core 物化；外层 next/fetchmany、切帧或 HTTP/2 均不足以证明全链路有界。[迁移后的 Native 实现](../../embedded/native/SonnetDB.Native/SonnetDbNativeExports.cs)、[嵌入式结果](../../src/SonnetDB.Data/Embedded/MaterializedExecutionResult.cs)、[Frame 通道](../../src/SonnetDB.Data/Remote/FrameChannel.cs)。

保留原 M49 的两项投入：各端类型化批读写/分析体验，以及执行器至消费者的有界读取。R01/R02/R03 对应 V45-X01/X02、M41/M42，R04 接 M46；不另建查询引擎、codec 或资源管理器。

### 类型、批次与生命周期

共享列顺序、原始标识符名称、逻辑类型、nullable、时间单位/时区、schema 身份与测试语料。NULL/缺失/空二进制/NaN、Int64 极值、UTF-8、稀疏、乱序、精确时间/向量均明确；不把未知值回退为 double/字符串。参数不由各语言拼 SQL。遵守 #211 的名称绑定规则。

每批行/编码/解码字节和请求累计行/字节/时间均有限；大值使用明确分块或拒绝。批缓冲的借用/复制与推进/释放时点一致，禁止无界预取；整 DataFrame 有独立总量上限。并发消费、Close/取消与句柄/缓冲所有权分别定义。

### 终态、写入与重构边界

完整结束、预算拒绝、截断、取消、断连、错误和未知终态分别表达；缺 end、计数不符或损坏帧不能当作成功 EOF。慢消费/提前关闭必须实际释放执行、网络、ABI reader、spill、缓存租约与预算。

批写复用引擎已有持久性、约束与适用事务；明确请求/批次原子或逐条确认，跨批不自动成为事务。保存已确认/被拒/未知提交区别，禁止盲目重放未知写。

用户要求直接重构，不维护旧 SDK 函数、混合 local/remote 门面、原 C ABI 或旧调用默认行为的兼容层。新 ABI/Frame 必须有明确版本和能力错误，不静默改变编号含义；原存储版本/迁移/拒绝旧格式规则不因 SDK 重构而放宽。

## 5. 推进与分批正式发行

1. **G0：C01 → C02。** 首批操作/平台矩阵、候选网络栈与小输入证据、批 schema/预算/错误/终态。
2. **G1：D01/F01 + R01/R02/R03/C03。** 先建立 .NET/C 的托管/AOT 本地与纯 Frame 远程切片，逐模型扩展；分清引擎、HTTP/2、编解码与 ABI 验收。
3. **G2：C04/C05/C06/C07。** Go/Rust/Python/Java 两条线，VB6/PureBasic 仅远程，各自按切片接入，Java8 单独运行。
4. **G3：R04/R05。** 以真实数据验证成本、资源和故障，按本批适用语言/平台冻结结果，不预填倍数。
5. **G4：C08 可分批执行。** 本批适用包完成后独立交付；不等待全部语言/平台，也不把单端通过升级为整个 M49 完成。

首个工程切片建议为 .NET/C 的 Windows x64 与 Linux x64；其它目标平台按真实工具链及依赖依次扩展。支持全平台是最终目标，不等于第一批已经支持全矩阵。C01 冻结每批范围与完成条件；每批均需自身适用的质量、真实服务、AOT、恢复及包消费者门槛。整个 M49 关闭需要所有最终目标收口，但不作为每个正式批次的统一前置阻断。

## 6. 验收矩阵

| 维度 | 必须取得的证据 |
|---|---|
| 结构 | 远程包不加载 Core/AOT 引擎；嵌入式无需 Server；BASIC 无嵌入式桥接 |
| 九模型 | 每个已支持操作有 .NET 托管、C ABI、Frame 和适用语言的真实结果；缺口逐项登记 |
| 协议 | Server 观察实际 HTTP/2、Frame 编解码/版本/终态；无 REST/HTTP1 静默回落；例外独立留证 |
| 正确性 | 同数据、schema、列名/类型/NULL/顺序/Int64/时间/向量；稀疏不能因批边界丢值 |
| 资源 | 扩大输入时在途内存/队列受控，Core/AOT/Server/各语言峰值分列，无隐藏完整 List |
| 故障 | 慢消费、提前关闭、批间取消、超限、大值、断网、未知提交、关闭重开与恢复 |
| 安全 | 已有鉴权授权继续生效、身份/错误不泄露秘密，模型预算不绕过 |
| 新版本 | ABI/Frame 版本与不支持错误明确；不要求旧 SDK/API 兼容回归；持久格式规则保留 |
| 分发 | 每批实际 RID/语言/依赖、匹配共享库/头文件、模型与跨模型 demo、干净消费者 |
| 性能 | 固定候选/机器/语料/持久性，首批/总耗时/吞吐/P95/P99/RSS/GC/I/O；本地与远程分开 |

Java JNI、可选 FFM、BASIC 源检查与真实编译/运行分别记账；缺工具保持 NOT_RUN，不用另一个语言通过替代。功能源代码、AOT 构建、真实 Server、性能、包消费者、发布和公开回读分列。

所有试验先小输入、固定项目数/并发/墙钟/内存磁盘预算，记录任务创建的进程身份并回收任务子树/临时对象；不安装或扫描不需要的工具，不碰共享缓存和外部进程。

## 7. 暂缓与当前状态

外部 S3/Azure 后端、冷数据直读、存算分离、Arrow 强制依赖、通用历史修订/AS OF、跨模型同点快照不扩入本批；现有模型内对象能力继续复用。普通 32 位库、平台治理/AI/CDC API 与 FFM 后续按需要独立推进。

实现会话已接管同一受管工作区：新增 Native 生命周期基线/回归，移除 ABI 层的全量结果复制，开始唯一 AOT 工程迁移。D01 的依赖隔离、F01、Core pull 执行、各语言包和平台验收仍待完成。真实结果以实施矩阵和根 HANDOFF 的本片记录为准；规划目标不得视为已交付。没有远端 issue/PR、推送或公开发布。
