# SonnetDB 固定讲解人物

更新：2026-11-06（Asia/Shanghai）。角色标识：`sonnetdb-explainer`，规范版本：`1.0`。**当前固定基准为 V5，后续人物生成必须遵守本档案。**

用户在查看 V5 后要求“提交代码并推送”，并明确“确保告诉智能体，以后按照这个规则生成”。本档案据此固定当前方案；旧候选和历史待确认收据不是可自由切换的角色版本。

使用 `gpt-image-design` 技能的 GPT Image 2.5 路径，当前已核模型为 `gpt-image-2.5-sunburst`；凭据沿用技能的受控本机桥接，不写进提示词、仓库、命令行或日志。模型不可用时按渠道规则保留失败/未知，不擅自更换模型。

## 固定角色和造型

| 部位 | 必须保持 |
| --- | --- |
| 身份与年龄感 | 同一个成年亚洲女性，约 25 岁，成年人的五官与身体比例。暂不赋予姓名、生日或现实人物身份。 |
| 脸与气质 | 以 V5 为准的同一张脸；甜美、可爱、亲切，自然温暖的微笑和清晰眼神，保留技术讲解员的专业感。 |
| 发型 | 深棕色长发、自然微卷、轻薄刘海，小薄荷色发饰。 |
| 上身 | 米白针织开衫及细薄荷包边、白衬衫。 |
| 裙装与领结 | 薄荷绿、米白、少量淡粉线条的格纹百褶裙与同款蝴蝶结；比例和长度参考 V5。 |
| 丝袜 | V5 的近自然肤色、极轻冷薄荷调、细腻轻透光泽；自然肤色与膝/小腿/脚踝明暗清楚。薄荷绿主要体现在服饰中，不能再把丝袜画成灰黄绿或不透的亮青色块。 |
| 鞋子 | 米白浅口包头高跟鞋、细收鞋跟、无厚重鞋台，轮廓以 V5 为准。 |
| 摄影风格 | 写实、自然皮肤和面料质感，柔和主光及适度轮廓分离，不改变为动漫脸或塑料娃娃质感。 |

袜子的 8–12D、鞋跟约 5–6 厘米只能作为生成时的轻透/鞋型视觉描述，不能声称从 AI 图中验证了实物参数。腿部表现依靠自然明暗与细腻光泽，不靠高饱和色覆盖。

## 可变项与背景规则

每篇可改变教学主题、技术图示、道具、动作、画面视角、横竖构图、留白与渠道尺寸。改变这些不等于更换人物；换脸、改发型、换发色、改变年龄感、换装、换鞋或改变固定材质，需要用户新的明确要求。

背景可随文章主题变化，但**人物与背景必须清楚分离**。默认使用低饱和、较深冷蓝灰的技术场景，配柔和偏暖主光与克制的轮廓光，衬托浅色服装和肤色。避免整片浅暖背景使人物和裙装混在一起；也不让强烈背景图示盖过人物脸部与教学重点。

保持自然讲解姿态。全身角色参考须完整看清双鞋与鞋跟；文章封面可按构图裁切，脸部仍须清楚，不能通过裁切掩盖不符的造型。

## 每次生成和发布前检查

1. 读取本档案、清单和模板，校验基准 SHA；将实际输入路径与 SHA 写入本次记录。
2. 以现有角色为输入进行编辑/参考生成，填入本篇已核主题。只在必要的文字和图示区域留白，不重新设计角色。
3. 保存本次提示词、模型、请求尺寸、实际尺寸、输出 SHA、来源和失败/未知记录。遵守技能/渠道的总时限、次数、取消和进程回收规则；密钥不得落盘。
4. 实际目视核对同一脸部、成年甜美气质、长发、格纹/开衫、轻透丝袜、自然腿部明暗、高跟鞋、背景分离、肢体与透视。
5. 核对中文可读性、SonnetDB 品牌和文章技术内容。不得创造性能数字、客户成果、零丢失或生产就绪声明；涉及 Graph 时保留 Beta。
6. 角色或内容不符则修正并重新审核；生成成功、审图通过、用户要求修订、上传与公开发表分别记录，不相互替代。

“每篇独立配图”指新主题、新构图和新输出文件，不等于每篇换一个人。参考图是输入，不能直接冒充渠道要求的每篇新人物图；按渠道保留新的输出 SHA 与事实审核。

设计须有独立判断，以配色协调、视觉中心、角色识别、轻透材质和缩小为封面后的可读性为依据；不得机械照搬最新参考，也不得在没有受众调查时宣称“大多数人更喜欢”。

## 范围

本档案约束后续 SonnetDB 讲解人物及带人物的封面、图文与视频素材。它不要求每张纯技术图必须出现人物，不改变各渠道独立配图、查重、事实审核、单次发布请求和权限规则。

已发布文章、冻结稿、其它渠道原图及历史回执不自动替换；历史资产替换须另有明确范围。本次提交推送不代表发布文章、上传平台素材或部署产品。
